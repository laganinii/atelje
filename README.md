# Atelje

**Atelje** is an iOS app: a creative desk ("moodboard") where you leave *traces* — notes, photo polaroids and links — on a pannable, pinch-zoomable desk, reply to them with sticky notes (*Threads*), connect them with `[[links]]`, keep references in an *Inbox* and see your own traces under *You*. The UI is in English (translated from the original Croatian artifact at extraction time, see `scripts/i18n-en.mjs`). Everything stays on the device: no account, no server, no tracking, works offline.

- Bundle ID: `ie.laganinii.atelje` · Version 1.0.0 (build 1 locally; CI uses the workflow run number)
- Stack: React (pre-built artifact bundle) + Vite 8 + Capacitor 8 (Swift Package Manager), iOS 15+
- Native plugins: Haptics, Share, Filesystem, Preferences, Status Bar, Splash Screen, Keyboard

## Project layout

| Path | What |
|---|---|
| `source/atelje-artifact.html` | The original single-file React artifact (the source of truth for the UI). |
| `scripts/extract-artifact.mjs` | Reproducible extraction: pulls the app bundle and CSS out of the artifact, drops the artifact-host scripts and remote fonts, and applies the App Store patches (persistence, share-sheet export, removal of the fake Apple sign-in, fake voice memo and developer notes, safe-area fixes), then translates the UI to English with `scripts/i18n-en.mjs`. Every patch must match exactly or the script fails. |
| `src/app/atelje-bundle.js`, `src/styles/artifact.css` | Generated by the script above (committed). Don't edit by hand; change the script and run `npm run extract`. |
| `src/native/bridge.js` | Native bridge: on-device storage (`window.AteljeStore`), share-sheet export (`window.AteljeNative`), `navigator.vibrate` → iOS haptics, status bar, keyboard, splash. |
| `src/main.js`, `index.html` | Entry: bundled fonts (@fontsource), CSS, bridge (hydrates storage first), then the app. |
| `ios/App` | Committed Xcode project (Capacitor 8, SPM). `Info.plist`, `PrivacyInfo.xcprivacy`, icon and splash assets live here. |
| `assets/`, `scripts/make-assets.mjs` | Icon and splash sources (`npm run assets` regenerates the Xcode asset catalogs). |
| `tests/build.test.mjs`, `scripts/check-ios.mjs` | Release checks: no remote URLs, fonts bundled, no developer notes / fake features, config sane; iOS project bundle id, version, privacy manifest, permissions. |
| `.github/workflows/ios-testflight.yml` | CI: build, test, unsigned archive, then sign + upload to TestFlight. |
| `docs/` | GitHub Pages site: support page, `privacy.html`, and `docs/app-store/` (listing draft, screenshots, review checklist). |

## Prerequisites

- Node.js 22+ and npm
- For running on iOS: a Mac with Xcode 26 (App Store uploads require the iOS 26 SDK)

## Build

```bash
npm ci
npm run build          # Vite → dist/
npm test               # checks dist/ (run after build)
npx cap sync ios       # copies dist/ into ios/App and updates native plugins
npm run check:ios      # static checks of the Xcode project
```

Shortcut: `npm run cap:sync` (build + sync). Web preview: `npm run dev`.

## Run on the iOS Simulator / a device (Mac)

```bash
npx cap open ios       # opens ios/App/App.xcodeproj in Xcode
```

Pick a simulator or your iPhone and press Run. For a device, select your team under *Signing & Capabilities* (automatic signing).

## CI / TestFlight

`.github/workflows/ios-testflight.yml` runs on `macos-15` and selects the newest installed Xcode 26 (App Store uploads require the iOS 26 SDK):

1. `npm ci`, `npm run build`, `npm test`, `npm run check:ios`, `npx cap sync ios`
2. Unsigned `xcodebuild archive` (proves it compiles, no secrets needed)
3. Checks the signing secrets — stops here with a clear error if any is missing
4. Exports a signed `.ipa` with Xcode automatic (cloud) signing using the App Store Connect API key
5. Uploads to TestFlight with `xcrun altool`

Triggers: **Actions → iOS TestFlight Build → Run workflow** (always runs), or pushes to `main` touching the app (only once all secrets are set).

### Secrets (Settings → Secrets and variables → Actions)

| Secret | Value |
|---|---|
| `ASC_KEY_ID` | Key ID of an App Store Connect API key |
| `ASC_ISSUER_ID` | Issuer ID (same page) |
| `ASC_KEY_P8` | Full contents of `AuthKey_<KEYID>.p8`, including the BEGIN/END lines |
| `APPLE_TEAM_ID` | 10-character Team ID (developer.apple.com → Membership) |

Create the key in App Store Connect → Users and Access → Integrations → App Store Connect API → Team Keys → "+", access **Admin** (needed so Xcode cloud signing can create the distribution certificate and profile). Download the `.p8` (only possible once). Then on the Mac:

```bash
gh secret set ASC_KEY_ID    -R laganinii/atelje --body "XXXXXXXXXX"
gh secret set ASC_ISSUER_ID -R laganinii/atelje --body "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
gh secret set ASC_KEY_P8    -R laganinii/atelje < ~/Downloads/AuthKey_XXXXXXXXXX.p8
gh secret set APPLE_TEAM_ID -R laganinii/atelje --body "XXXXXXXXXX"
gh workflow run ios-testflight.yml -R laganinii/atelje
```

Never commit the `.p8` (it's in `.gitignore`).
